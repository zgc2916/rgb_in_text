# v3.0 源码快照

发布日期：2026-10-31。仓库：`zgc2916/rgb_in_text`，标签：`v3.0`。

本版本基于远端 `v2.0` 的提交历史，归档当前 CLIP RGB/T 指代表达定位优化代码、测试和研究文档。`v3.0` 是源码版本号；它不代表测试集已经达到 74%，也不代表所有探索模块都已取得有效提升。

## 包含的改动

- C1 红外细节与边界定位模块、训练控制及消融报告。
- 局部模态交换、可靠性交换、软空间交换、区域锚点和原生分辨率再观察实验。
- 空间定位质量、目标尺度保护与相对几何损失实验。
- 单模型后期视觉 LoRA、融合层与解码层适配；按有效优化器步更新的参数 EMA。
- 三种子训练、验证集选择、冻结 checkpoint 后的测试评价和断点恢复流程。
- 权重精确差分存储、已完成实验的重复权重清理及相关测试。

各实验保留独立控制器；归档某个模块不表示推荐启用它。具体实验设置和已有负结果见 [优化记录](CLIP_NEXT_OPTIMIZATION_2026-10-27.md)。

## 最新已完成实验

`2026-10-28_late_adaptation_ema_r1` 已完成三个种子各 30 epoch，共 90 epoch。每个模型由验证集选择 raw 或 EMA 参数后单独测试，测试结果不用于更改该次选择。

| 单模型种子 | 测试 Acc@0.5 | 测试 Acc@0.7 | 测试 mIoU |
| --- | ---: | ---: | ---: |
| 13 | 72.719% | 54.087% | 61.623% |
| 14 | 73.717% | 55.798% | 62.258% |
| 15 | 73.241% | 56.036% | 62.288% |
| 三次独立模型的算术平均 | 73.226% | 55.307% | 62.056% |

上表平均值不是模型集成结果。测试集有 2104 条表达；Acc@0.5 达到 74% 至少需要命中 1557 条，本轮最好命中 1551 条，尚未达标。该方法也未通过预注册的验证提升门槛，因此报告中的正式推荐仍为原 C1。适配与 EMA 是已有训练方法，本版本不据此声称新的模型结构或已证实的创新性。

## 资源与运行条件

源码不包含数据集、CLIP/BERT/InfMAE/MMVG 预训练权重、C1 权重、训练输出、逐样本预测或重复的运行源码快照。第三方 `models/swin_model` 目录继续沿用此前版本的外部依赖边界。

`run_resources/c1_recipe.json` 与 `run_resources/c1_references.json` 保存 C1 配置、三个种子的基准指标及 checkpoint 校验值；它们不是权重文件。当前研究控制器保留原训练环境的绝对资源路径。迁移环境时，需要准备相应资源并核对这些配置，以及 `script_train/clip_lavs_control/runtime.py` 中的 `ORIGINAL`、`REFERENCE`、`PYTHON` 和各控制器默认输出目录。GPU 预检还需要原 C1 验证预测及配置，详见对应控制器的 `prepare` 实现。

在资源和环境已配置、且使用新的实验目录时，后期适配控制器入口为：

```bash
python -m script_train.clip_late_adaptation_control.control --help
```

可在不启动训练的情况下运行源码回归测试：

```bash
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 PYTHONPATH=. python -m pytest -q tests
```

本次发布前在独立发布目录中运行上述测试：192 项通过，2 项跳过。

历史教学文档保留在仓库中；其中的本地训练输出链接需要原实验文件，源码标签本身不提供这些文件。
